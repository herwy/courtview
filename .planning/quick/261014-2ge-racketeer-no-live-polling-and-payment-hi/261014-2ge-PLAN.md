<decisions>
Choices made on the open points:
- Guard mechanism: one @app.before_request hook, not a per-route decorator. It covers all 13 routes, the proxy and any future /api route in one place.
- Cache-only routes (/api/month, /api/heatmap, /api/court-popularity) also return 410 for Racketeer. The rule is "everything under /api/ except /api/archive/", which is simpler to state and verify than a per-route list.
- Guard ordering: the hook checks the token itself (no failure recording) and returns None for unauthenticated requests, so the route's _gate still produces the 403 and rate-limit accounting. 410 is never shown to unauthenticated callers.
- Revenue month navigation for Racketeer: both arrows disabled; revMonthLbl shows the selected snapshot's month plus " (archive)", derived from captured_at in Europe/London (no hardcoded "June 2026"). revMonth itself is not changed, so other clubs keep their month.
- Archive selector loses the "Live" option entirely (it is Racketeer-only) and auto-loads the latest snapshot (the snapshots API is ordered DESC).
- Payment loading chunk: keep fetching sequentially until >= 25 new rows, 7 requests, or month start (same rule for initial load and each Load More click, so a click never lands on an empty day and appears to do nothing).
- Default club for first-time visitors stays CLUBS[0] (Racketeer). Not in scope; flag in the summary as an open item.
</decisions>
