<objective>
Fix the /access page always showing 127.0.0.1 as client IP.

Purpose: CourtView runs behind Caddy, which proxies 47200 -> 127.0.0.1:8766. Flask sees only
the loopback connection from Caddy and has no access to the original client IP unless Caddy
forwards it in a header. The /access page therefore logs every request as 127.0.0.1.

Output: Caddyfile updated to forward X-Real-IP on both vhosts; courtview.py updated to read
that header; Caddy reloaded; courtview redeployed.
</objective>
