| Boundary | Description |
|----------|-------------|
| journal -> Telegram | Journal lines (attacker-influenced via request logging or error text) are embedded in HTML sent to Telegram |
| systemd -> script argv | %i / --check-recovery unit name becomes systemctl/journalctl argv |
| state file | Root-owned JSON read and written by the notifier |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1p4-01 | Tampering | format_alert logs/cause | mitigate | html.escape every journal line and the cause excerpt; tests assert `<script>` never appears raw |
| T-1p4-02 | Elevation | main() argv | mitigate | _UNIT_RE plus '..' rejection in both modes; subprocess list argv, never shell=True |
| T-1p4-03 | Information disclosure | logs blockquote | accept | last 5 lines of courtview's own journal; gunicorn logs no tokens (access log is a separate JSONL file); spec forbids secrets and full token URLs |
| T-1p4-04 | Tampering | unit_failure_state.json | mitigate | atomic_write_json with mode 0600; malformed JSON falls back to empty state |
| T-1p4-05 | Denial of service | ExecStartPost systemd-run | mitigate | leading `-` so a systemd-run failure never blocks courtview starting; --collect cleans transient units |
</threat_model>
