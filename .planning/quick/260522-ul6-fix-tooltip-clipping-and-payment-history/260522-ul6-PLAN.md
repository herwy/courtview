<objective>
Fix two UI bugs in courtview.html:

1. Tooltip clipping: `.tt` tooltips are cut off by `.grid-scroll { overflow-x: auto }` which forces
   overflow-y to non-visible. Fix by switching to `position: fixed` with JS event-delegation positioning.

2. Payment history ordering: the Padelmates API returns data oldest-first and ignores sort params.
   Fix by loading the most recent 14-day window on initial load and shifting the window backwards on
   "Load more" instead of incrementing a skip offset.

Purpose: Both bugs make the Revenue and booking tabs harder to use. The tooltip bug hides booking
         details. The payment bug buries recent transactions behind many load-more clicks.
Output: Updated courtview.html, deployed to RPi.
</objective>

  <files>courtview.html</files>
  <action>
    Make three changes in the CSS/JS for the `.tt` tooltip:

    CSS (around lines 311-321):
    - In the `.tt` rule: change `position: absolute` to `position: fixed`. Remove the three lines
      `bottom: calc(100% + 6px); left: 50%; transform: translateX(-50%);`. Leave all other properties
      (display:none, background, border, border-radius, padding, white-space, max-width, z-index,
      font-size, color, box-shadow, pointer-events:none) intact.
    - Delete the rule `.cell:hover .tt { display: block; }` entirely. CSS hover is replaced by JS.

    JS (add near the end of the script block, before the closing `</script>`):
    Add an event-delegation block on `document` for `mouseover` and `mouseout`. Key details:
    - `mouseover` handler: walk `e.target` up with `closest('.cell')`. If found, find its child `.tt`.
      Set `tt.style.display = 'block'`. In a `requestAnimationFrame` callback: get
      `cellRect = cell.getBoundingClientRect()` and `ttRect = tt.getBoundingClientRect()`. Compute:
        `top = cellRect.top - ttRect.height - 6`
        `left = cellRect.left + cellRect.width / 2 - ttRect.width / 2`
        `left = Math.max(8, Math.min(left, window.innerWidth - ttRect.width - 8))`
      Set `tt.style.top = top + 'px'` and `tt.style.left = left + 'px'`.
    - `mouseout` handler: walk `e.target` up with `closest('.cell')`. If found and
      `!cell.contains(e.relatedTarget)`, find its `.tt` and set `tt.style.display = 'none'`.
    - Use two separate `document.addEventListener` calls (one for `mouseover`, one for `mouseout`).
  </action>
